A fast, read-only make.fun frontend in plain static files — no framework, no build step, no sign-in. It shows the live bounty board (pot, entry fee, time left, entries), a bounty's page with its live rewards table, that bounty's leaderboard, and any account's public profile, each reachable by a link and by its own hash URL. API answers are cached in memory and revalidated with ETags; the first load is a few kilobytes.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
